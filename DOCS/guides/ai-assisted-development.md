# AI-assisted plugin development

The SDK archive and each project generated by `lunaris-core create-plugin`
include an `AGENTS.md` and two skills under `.agents/skills/`:

| Skill | Use |
| --- | --- |
| `lunaris-plugin-development` | Create or change a plugin, choose public contracts, debug activation and produce a local package. |
| `lunaris-plugin-review` | Review source or a local `.lup` for compatibility, lifecycle and handoff. |

Start in the extracted SDK root when creating a project. Follow
[First plugin](../quickstart/first-plugin.md) to install the toolchain.
Open the generated project directory in the agent for subsequent work.
Codex can discover the local `.agents/skills/` folders and `AGENTS.md`.
See [OpenAI Docs on skills](https://learn.chatgpt.com/docs/build-skills)
and [project instructions](https://learn.chatgpt.com/docs/agent-configuration/agents-md).
With an agent that does not scan those paths, direct it to the project's
`AGENTS.md` and the relevant `SKILL.md`. To update an existing project,
copy the two skill directories from the archive and merge relevant
instructions into its existing `AGENTS.md`.

The skills use files and commands from the SDK. The archive does not need
an AI service configuration or API key to build or test a plugin.
Agents can list available contracts with `npm run core -- contracts`
inside a project. Confirm method signatures and permissions in the installed
declarations before implementation. The [recipes](plugin-recipes.md) and
[platform guide](compatibility.md) explain when a contract requires Web
or Windows rather than a headless host.

Example requests for an agent:

- “Use `lunaris-plugin-development` to add a settings toggle to this plugin.
  Persist it per Vault. Verify the public contracts and run focused checks.”
- “Use `lunaris-plugin-development` to add a decoration to the existing status
  bar. Use Drema as a reference. Make sure disabling the plugin removes it.”
- “Use `lunaris-plugin-review` to check this `.lup` and the source change for
  platform support and cleanup. Inspect the archive without activating it.”

These files are authoring guidance. The plugin packer bundles the entry,
manifest and `assets/`. The skills and `AGENTS.md` stay in the SDK and
project.
