## Reproduction and evidence

From installed Node/npm prerequisites, run `npm ci`, `npm run build`, then `npm run release:check`. The release script builds/checks all six workspaces, runs runtime/type/import tests, rejects skipped required tests, checks public exports/diagnostics/local docs links, measures performance and rehearses the generated-plugin workflow. `npm run ci` uses `CI_BASE_SHA` (a validated full Git SHA) to select touched scopes for a PR; without it, checks the full core. Remote CI was configured but not executed in this session.

Verified environment: Windows x64, Node 26.13.0, npm 11.20.0, TypeScript 6.0.3; dependencies are locked. Generated dependencies/compiler use offline links to the built source checkout. Initial root dependency download time depends on registry/cache availability. Terminal Ctrl+C/SIGTERM handlers are wired; automated live-dev acceptance uses the supported stdin `stop` command, not desktop automation.

Initial quickstart sample: 1062 ms for generation, cached offline install, build, validate, actual plugin test, inspect and dev/stop after checkout dependencies/build existed. The final rehearsal additionally invokes generated npm convenience scripts. Reproduce with `npm run rehearse`; this is a measured cached/local scenario, not an internet download-time guarantee.

## Known limits

Trusted local code shares a JavaScript realm and Node ambient globals. SDK checks are mediation, not containment. Values/returned objects are not deeply isolated. Deadlines cannot terminate synchronous/noncooperative JavaScript or undo external effects; pending cleanup is reported honestly. Native async-context attribution is absent, so indirect host-closure self-waits are deadline-bounded rather than universally detected.

The loader checks real paths before import but is not a signed/race-proof package installer. Top-level module initialization is ordinary Node evaluation and is not bounded by activation deadlines. Node module caching requires a new process after code changes. The source checkout must remain available for generated local dependency links. CLI grants default to empty; applications needing policy compose the development host API. Browser/native/editor/UI features and public registry distribution are not implemented. Only the documented Windows environment has execution evidence.
